# 🎬 CineMax - Movie Booking Platform (System Analysis & Frontend)

## 📌 Project Overview
An end-to-end academic project focusing on **System Analysis & Design (SAD)** and **Frontend Development** for an online movie booking system. The project bridges user requirements with technical execution, translating functional specifications into UML architecture and interactive user interfaces.

## ✨ Key Features Implemented (Frontend)
* **User Authentication:** Registration and login validation flows.
* **Movie Discovery:** Real-time search, movie details, trailers, and ratings.
* **Interactive Seat Booking:** Dynamic seat map, booking summary, and checkout logic.
* **Review & Rating System:** Audience rating calculation and feedback history.

## 🛠 Tech Stack
* **System Design:** Draw.io (UML)
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
